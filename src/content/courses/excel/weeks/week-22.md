## Day 1 — Monday
**Topic:** The exam and the objectives
**Time:** ~1 hour

### Review (10 min)
Re-read your Phase 1–3 logs: note anything that still feels slow.

### Lesson (15 min)
**MO-210 format:** ~50 minutes, a **live Excel** project-based exam (you perform tasks in real files, not multiple choice). Passing score **700/1000**. You get a certificate and a Credly digital badge.
**The 5 skill areas** (from the official outline):
1. **Manage worksheets and workbooks:** import data (CSV/text), navigate (Name Box, Go To, hyperlinks), format (page setup, headers/footers, themes), customise options and views (freeze, split, properties), print settings, inspect/save in other formats
2. **Manage data cells and ranges:** paste special, fill series, insert/delete, merge, formatting, styles, clear formats, **named ranges**, summarise data (sparklines, conditional formatting)
3. **Manage tables and table data:** create/convert tables, table styles, total row, add/remove rows and columns, filter and sort (multi-level)
4. **Perform operations with formulas and functions:** relative/absolute/mixed refs, named ranges in formulas, SUM/AVERAGE/MIN/MAX/COUNT/COUNTA/COUNTBLANK, IF, SORT and UNIQUE, text functions (LEFT/RIGHT/MID, UPPER/LOWER/PROPER, LEN, CONCAT, TEXTJOIN)
5. **Manage charts:** create, modify (data source, add/remove series, switch row/column), layouts and styles, **alt text** for accessibility

### Practice (20 min)
Download the official outline and tick each objective: ✅ confident, 🟡 slow, ❌ don't know. The ❌ and 🟡 items are your study plan for Tuesday–Thursday.

### Mini-Task (10 min)
Things people often miss: add **alt text** to a chart; **inspect a workbook** for hidden properties; **save as PDF with only a selection**; **display formulas**. Try each now.

### Log (5 min)
Log your ❌/🟡 list.

## Day 2 — Tuesday
**Topic:** Areas 1–2 speed drills
**Time:** ~1 hour

### Review (10 min)
Anki-style: say the shortcut for Format Cells, Go To, fill down, insert table, AutoSum, display formulas.

### Lesson (15 min)
Exam technique:
- Read **every word** of each task. "Named range", "table", "cell", "worksheet" all matter.
- Do **exactly** what's asked, nothing extra. Extra formatting can cost marks.
- Don't close the project file between tasks; use **Mark for review** and come back to hard ones.
- Watch the time: roughly a minute per task.

### Practice (20 min)
Timed drills (2 minutes each): import a CSV with the correct delimiter · set print area + print titles + landscape + fit to 1 page wide · add a header with the file name and page number · create a named range and use it in a formula · add a hyperlink to another sheet · apply a cell style · add a line sparkline · apply a Top 10% conditional format · remove conditional formatting from a range.

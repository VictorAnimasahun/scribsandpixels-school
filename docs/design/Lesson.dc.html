A function is a named block of code you can run whenever you want. You define it once with def, then call it as many times as you need. It can take parameters (inputs) and return a value (output).

# Basic shape: study this carefully
def function_name(parameter):
    # code goes here
    return something

Imagine you wrote 20 lines to check a password. Without a function you copy those 20 lines everywhere. With one, you write it once and call it everywhere.
